## 💡 Featured Projects

- **[Social Pulse](https://github.com/AparAgarwal/social-pulse-backend)** — Production-ready social media REST API with JWT authentication, refresh token rotation, and a modern React + TypeScript frontend ([frontend repo](https://github.com/AparAgarwal/social-pulse-frontend)).

- **[URL Shortener](https://github.com/AparAgarwal/url-shortener)** <i>[🔗 Live Demo](https://url.aparagarwal.tech)</i> — URL shortening service with REST APIs, JWT authentication, click analytics, and XSS/NoSQL-injection protection. Deployed on Vercel with a custom domain.

- **[Blog Website](https://github.com/AparAgarwal/blog-website)** — Production-ready Next.js 16 blog platform with MDX content, secure admin dashboard, ISR caching, dark/light theme, and WCAG-compliant accessibility.

- **[Library Management System v2](https://github.com/AparAgarwal/library-management-v2)** — Full-stack application with role-based access control, real-time SSE notifications, Redis caching, and fully Dockerized deployment (Node.js + React + PostgreSQL).

- **[KernelCanvas](https://github.com/AparAgarwal/KernelCanvas)** — Web-based Docker container management tool for visualizing containers and system state using React and Node.js.

- **[Campus Navigator](https://github.com/AparAgarwal/campus-navigator)** — Flutter mobile application for indoor campus navigation with Google Maps, real-time location tracking, and route optimization.

- **[ParseLoom](https://github.com/AparAgarwal/parseloom)** — Interactive educational tool for visualizing LL/LR parsing algorithms in compiler design.
